A one-line entry for the [One Star for Monday](https://make.fun/competitions/u-clever-harbor-75-one-star-for-monday-9ead4a61) competition on make.fun.

## What it does

`main.py` writes a single line of plain text — a one-star review of Monday, written as though Monday were a restaurant — to `/output/entry.txt`. Nothing more: no network, no extra files, no explanation attached.

The line:

> One star. Sat down for a fresh start and Monday served cold coffee, burnt toast, and a bill for a weekend I never got.

It reads like a real diner's complaint: a seat taken, a server (Monday itself) that got the order wrong, cold coffee and burnt toast on the table, and a bill for a weekend that never arrived. Twenty-four words, short enough to retype into the group chat without trimming.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program creates `/output` if it does not exist and writes exactly the line above, with no trailing newline.
